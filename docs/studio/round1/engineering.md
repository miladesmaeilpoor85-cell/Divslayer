# Ember & Iron 0.26.1 — engineering audit (code and configuration, phone eyes)

Nothing in `/home/claude/studio/game` was edited. Paths are relative to that folder. Measurements were made headless on a
2-core Xeon 2.1 GHz with a private `XDG_DATA_HOME`; the export check and the "missing file" run were done on a throw-away
copy in the scratchpad. Headless numbers are script/engine CPU only (no GPU, no canvas tessellation).

Confidence words: **measured** = I ran it; **read** = read in code; **inference** = reasoning from the code, not observed.

## Looked at and fine

- **`boss._echo_look` (`scripts/boss.gd:272-297`)**: one Sprite2D and one tween every 0.12 s while moving, 0.5 s standing, each freed by its own tween after 0.42-0.9 s; at most about 4 alive per echo boss; skipped at fx quality 0; the tween belongs to the ghost, so a freed world takes it along. Noise.
- **`player._sig_step` (`scripts/player.gd:1042-1060`)**: a ring every 10 physics frames and a tick per second, only while the fire or the ward is up. Rings are dictionaries in `fx.rings`, filtered every frame (`scripts/fx/fx.gd:216-228`), no nodes. Noise.
- **HUD per frame (`scripts/hud.gd:407-451`)**: status chips are rebuilt only when the whole-second key changes; the sky chip only on a key change; no per-frame Label writes apart from that. Turning the whole HUD `_process` off changed nothing measurable in the village.
- **Minimap (`scripts/ui/minimap.gd:22-26`)**: redrawn 10 times a second, not every frame.
- **Coroutines after `await`**: `_brann_step`, `_wyrm_stirs`, `_zahhak_bound`, `_chapter_end`, `_on_boss_down`, `_thalia_pays` (`scripts/main.gd:479-481, 515-517, 647-657, 673-675, 681-683, 724-730`) all check `hud` after the wait, and `_quit_to_title` sets `hud`/`world`/`player` to null (`main.gd:175-181`), so the checks work. `_travel`, `start_ng` and the Boss Rush (`scripts/rush.gd:103-105, 144-146, 167-169, 197-199`) await `hud.fade_out()`, whose tween dies with the HUD, so they never resume on a freed HUD. The one gap is finding 9.
- **Signals on map change (`scripts/main.gd:121-134`)**: connected on the new world each time, the old world is freed with its connections; the two persistent ones are guarded with `is_connected` (`:128`, `:152`). World nodes connect bound methods to `Game.stats_changed` / `lang_changed` (`scripts/world.gd:193, 390, 882, 976, 1024`), which Godot drops when the node is freed.
- **`static var away` (`scripts/tutorial.gd:123`)**: reset when the yard is built (`scripts/training.gd:34`) and only read while the map is the village (`tutorial.gd:126`); no stale state across maps or a quit to title.
- **`UI.icon` cache (`scripts/ui.gd:167-181`)**: keyed by name, pixel size and stroke; callers use a handful of fixed sizes, so it is bounded.
- **Threads and audio**: the only thread use is the sample synthesis in `scripts/music.gd:99`, joined in `_exit_tree` (`:103-106`) and in `_process` (`:182-184`); `loop_end = buf.size() - 1` is in place (`music.gd:340`). Nothing from the "Android-only crashes" notes has come back.
- **Hit-stop (`scripts/world.gd:617-621`)**: the timer ignores time scale and its lambda touches only `Engine`, so a world freed during a hit-stop still restores `time_scale`.
- **Export filter**: the Android pack (1082 files, 23.5 MB) contains no `tests/`, `tools/`, `docs/`, `signing/`, `.md`, `.pem` or `.p12`. `assets/art/Props` and `Projectiles` are excluded and no script or data file loads from them. Every exported texture's name appears in scripts or data (the only name misses were numbered sound variants, loaded by pattern).
- **Android settings**: both `arm64-v8a` and `armeabi-v7a` on; the official 4.6.2 template is min SDK 24, target SDK 35 (from the template's `config.gradle`); the only permission is `vibrate`, and it is used (`scripts/game.gd:302-305`); immersive mode on; orientation sensor-landscape (`project.godot:27`); renderer Compatibility for desktop and mobile (`project.godot:36-37`); stretch `canvas_items` + `expand` on an 854x400 base with safe-area handling in `scripts/hud.gd:205-211`; package `ir.emberiron.game`; version name equals `Game.VERSION`.
- **Autosave on background**: `NOTIFICATION_APPLICATION_PAUSED` saves position and state (`scripts/main.gd:338-343`).
- **Script cost per map** (existing `tests/perftest.gd`, night + weather, hero fighting): 0.72-1.74 ms per frame, worst single frames 3.8-20.4 ms (dungeon), 430-650 nodes, up to 212 particles.

## Could not determine without a device

- **GPU cost of the light map**: `scripts/fx/lighting.gd:61,120` renders a 0.34-scale SubViewport every frame and multiplies it over the screen, plus a glow pass; only "fx = 0" turns it off (`lighting.gd:88-89`). Whether a Mali-T/G5x class phone holds 60 fps with it on is unknown. There is no frame-rate cap or automatic fallback (no `Engine.max_fps` anywhere), so a weak phone will run hot rather than at a steady 30.
- **Real cost of finding 3 on the render thread**: the antialiased arcs are tessellated by the renderer, which the headless run does not do; the phone cost is higher than my CPU share suggests.
- **Whether any target phone refuses textures above 2048 px or 4096 px** (finding 5), and peak memory on a 2 GB phone at a map change.
- **Freeze length at a map change**: `goto_map` builds the world and decodes a ground of up to 3000x2400 synchronously behind the black fade (`scripts/main.gd:162-166`).
- **Store rules**: I did not verify what Myket and Cafe Bazaar require in 2026 for target SDK, 64-bit, multiple APKs per release or APK size limits. Target 35 / min 24 with both ABIs is the safe side of what I know; check their developer pages before upload. Without a Gradle build the SDK levels cannot be changed from the preset.
- **Back gesture behaviour in immersive mode** on the tester's phone (finding 6), and how the default splash and icon look (finding 13).
- **`pad.size` was (854, 854)** in my headless run on an 854x400 project; probably a headless window artefact, but worth one look on a phone: is the touch pad's height the screen's height?

## How the measurements were made

- `godot --headless --fixed-fps 60 --path . -- --test res://tests/perftest.gd` (existing test).
- A/B frame cost: a small script outside the project (scratchpad `bench.gd`) run through `--test`, turning one subsystem's `_process` off at a time over 360 frames (trimmed mean). Village: base 1.15 / 1.22 ms, pad off 0.67. Emberforge (15 foes): base 1.44 / 1.27 ms, pad off 0.82. Other toggles were within noise (about +-0.2 ms).
- Export: `godot --headless --export-pack Android pack.zip` on a copy of the project, then the zip listing.
- Missing Wyrm: on the copy, removed `ancientwyrm.png` with its import files (what the Android pack looks like), loaded `wyrmhollow`, printed the boss's frame texture.
