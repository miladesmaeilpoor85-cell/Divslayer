## Reviewed and correct

1. **Saves (game.gd, achievements.gd, menu.gd)** — `write_safe` verifies the side file, keeps the last valid file as `.bak`, never backs up a damaged main; a damaged or empty main with a good `.bak` loads and the next save repairs the main (probe2); both damaged -> main kept as `save.broken.json`, new save written; a leftover `.tmp` is truncated on the next write; no code deletes the save anywhere in `scripts/`, so there is no "delete" path that leaves a `.bak` behind; settings and the profile use the same pair and read `.bak` too; `Ach.reset()` goes through `save()` so tests still start empty. Not testable here: `rename_absolute` on a real Android device (POSIX rename replaces the target, so it should hold).
2. **main.gd** — Back: closes shop/forge/cauldron, then toggles the pause menu; ignored when the tree is paused by something else; on the title it goes back a page or quits; with neither HUD nor menu it quits; `quit_on_go_back=false` is set. Back 0.3 s after death opens nothing and the death panel still opens (probe3). Debug gating: no script outside main.gd reads the arguments, so a release build needs none of them; `--test ... --playtest` still runs in debug with `Game.testing` false. The 1 s death timer now waits while paused and the guard cannot be passed by a living hero. `state.x/y` is read only by `start_world`; rematch, respawn, Boss Rush end and death use their own spots (problem only as in finding 1). The exit disconnect in `goto_map` is guarded with `is_connected`.
3. **world.gd exits** — the watch runs only when armed, only for the hero of this world, only after 20 px of movement; Boss Rush maps keep `exits_armed` false; one Timer per map, child of the map, freed with it and paused with the tree; the 0.6 s timer is guarded against a freed map. Sealed exits: one message in 3 s, hero pushed out (probe1, forest and shadowfen -> peaks). No map's spawn point is within 25 px of an exit (checked all `data/Maps/*.json`), so no bounce-back.
4. **touch_pad.gd** — every frame while a thumb is down, a button is held, the Talk button grows or shrinks, a drill glows, or within 200 ms of a press; every second frame for cooldowns, the charge and the ready Ultimate; otherwise 10 times a second (stamina, mana, ghosting, buttons appearing: at most 0.1 s late). Any touch event and a language change request a redraw; `release_all()` is at most 0.1 s late.
5. **UI** — minimap/sky: unchanged at Small and Normal (foot stays 156 at 400 px height), at Large the foot is about 113 and clears the Ultimate ring. Dialogue: alignment now relies on the RTL panel flipping it, English stays left, the hint at the end in both languages (not checked on a picture by me). Skills: only the order changed, `Bind%d_%s` names kept. Tap outside: the panel sits above the backdrop and stops the tap, so choosing an item cannot close it; `close` exists on all three; one tap closes once (probe1: `closed` emitted 1 time, nothing listens to it anyway).
6. **Balance** — the four JSON files parse; V12_BAL changed only `AREA/zahhakcave/dmg`, `BOSS/boss2/hp`, `BOSS/matriarch/hp`, `BOSS/zahhak/hp`; SHOPS, RECIPES and V12_CRAFT changed one description each and they match `50 + floor(30% of max health)`. A hero with only Greater Potions drinks at any missing health.
7. **export_presets.cfg / project.godot** — only the wyrm exclude, version code 29 / name 0.27.0, and `quit_on_go_back=false`.
