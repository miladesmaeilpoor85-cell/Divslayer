# Contributing | راهنمای مشارکت

Thank you for considering contributing. We welcome respectful contributions worldwide.

از علاقه شما به همکاری سپاسگزاریم و از مشارکت محترمانه افراد در سراسر جهان استقبال می‌کنیم.

## Before starting / پیش از شروع
1. Read [LICENSE](LICENSE), [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md), and [CLA.md](CLA.md).
2. Open an Issue to discuss substantial changes before starting.
3. Submit third-party assets only with documented source and compatible permissions.
4. Never include signing keys, credentials, private data, or unlicensed media.

## Workflow / روند کار
1. Find or open an Issue.
2. Fork the repository and create a focused branch, e.g. `feature/combat-tuning`.
3. Make a clearly scoped change.
4. Test in the relevant Godot version/device and describe results.
5. Submit a PR, link the Issue, and include screenshots for visual changes when useful.
6. Respond to review feedback.

## Areas / حوزه‌ها
- Gameplay and combat / گیم‌پلی و مبارزه
- Art and animation / هنر و انیمیشن
- World, quests, narrative / جهان، مأموریت و روایت
- UI/UX and accessibility / رابط کاربری و دسترس‌پذیری
- QA and Android testing / تست و تضمین کیفیت اندروید
- Audio and localization / صدا و بومی‌سازی

A PR is not guaranteed to be accepted. Maintainers may request changes or decline contributions for quality, security, licensing, or roadmap reasons.

پذیرش PR تضمین‌شده نیست و ممکن است به دلایل کیفیت، امنیت، مجوزها یا نقشه راه رد شود.
