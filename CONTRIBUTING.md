# Contributing | راهنمای مشارکت

Thank you for your interest in Divslayer.

از علاقه شما به بازی دیوکش سپاسگزاریم.

## Current status / وضعیت فعلی
You may use GitHub Issues to report bugs, suggest features, and discuss the project. **Please do not submit pull requests containing code, art, audio, translations, or other contributions for inclusion at this time.** The project license is proprietary and the contributor agreement is still an unapproved draft. A clear contribution and acceptance process has not yet been established.

می‌توانید از بخش Issues برای گزارش باگ، پیشنهاد قابلیت و گفت‌وگو درباره پروژه استفاده کنید. **لطفاً در حال حاضر درخواست ادغام شامل کد، تصویر، صدا، ترجمه یا مشارکت دیگری برای اضافه‌شدن به بازی ارسال نکنید.** مجوز پروژه اختصاصی است و توافق‌نامه مشارکت‌کنندگان هنوز پیش‌نویس تأییدنشده است. روند روشن مشارکت و پذیرش هنوز ایجاد نشده است.

## Before any future contribution / پیش از هرگونه مشارکت در آینده
1. Read [LICENSE](LICENSE), [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md), and [CLA.md](CLA.md).
2. Wait until the project publishes a reviewed contribution process and explicit acceptance terms.
3. Do not submit third-party assets unless their source and compatible permissions are documented.
4. Never include signing keys, credentials, private data, or unlicensed media.

1. فایل‌های مجوز، منشور رفتار و توافق‌نامه مشارکت را بخوانید.
2. تا زمان انتشار روند مشارکت بررسی‌شده و شرایط پذیرش روشن صبر کنید.
3. دارایی اشخاص ثالث را بدون ثبت منبع و مجوز سازگار ارسال نکنید.
4. هرگز کلید امضا، اطلاعات ورود، داده خصوصی یا محتوای بدون مجوز را ارسال نکنید.

## Future workflow / روند احتمالی آینده
If contributions are opened later, the project will publish the required workflow, testing expectations, and acceptance process here. Submitting a pull request will not guarantee acceptance.

اگر در آینده مشارکت‌ها فعال شوند، روند لازم، شیوه تست و فرایند پذیرش در همین فایل اعلام خواهد شد. ارسال درخواست ادغام به‌معنای تضمین پذیرش نیست.
