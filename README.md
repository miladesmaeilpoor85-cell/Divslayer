# Divslayer | دیوکش

A Persian-mythology-inspired action RPG made with Godot 4.6.

یک بازی اکشن نقش‌آفرینی با الهام از شاهنامه و اسطوره‌های ایرانی، ساخته‌شده با Godot 4.6.

**Status / وضعیت:** This public repository currently contains project documentation only. Game source and assets have not yet been imported.

این مخزن عمومی فعلاً فقط شامل اسناد پروژه است و کد و دارایی‌های بازی هنوز منتقل نشده‌اند.
