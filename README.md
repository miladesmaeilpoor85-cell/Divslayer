# Divslayer | دیوکش

A Persian-mythology-inspired action RPG made with Godot.

یک بازی اکشن نقش‌آفرینی با الهام از شاهنامه و اسطوره‌های ایرانی، ساخته‌شده با Godot.

**Status / وضعیت:** The sanitized game source and project assets are now present in this public repository. The project is still under development.

**وضعیت:** کد منبع پاک‌سازی‌شده و دارایی‌های پروژه اکنون در این مخزن عمومی قرار دارند. توسعه بازی ادامه دارد.

## Goals / اهداف
- Welcome developers, artists, designers, testers, audio creators, and translators worldwide.
- Keep official publishing, distribution, branding, and release decisions under the project owner's control.

- استقبال از برنامه‌نویسان، هنرمندان، طراحان، تست‌کنندگان، سازندگان صدا و مترجمان از سراسر جهان.
- حفظ کنترل انتشار رسمی و تصمیم‌های تجاری نزد مالک پروژه.
