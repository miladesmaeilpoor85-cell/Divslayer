# Audio credits | اعتبارهای صوتی

This file documents the audio assets currently listed in `data/audio_credits.json`. It replaces the older list of borrowed music that no longer matches the current soundtrack.

این فایل دارایی‌های صوتی فعلی را مطابق `data/audio_credits.json` مستند می‌کند و جایگزین فهرست قدیمی موسیقی‌هایی است که دیگر با موسیقی فعلی بازی مطابقت ندارند.

## Original soundtrack / موسیقی ساخته‌شده برای بازی

The repository's production notes identify the 30 instrumental soundtrack takes below as generated for Divslayer with Suno V6 through the Hoosha API. **These tracks are not CC0.** The metadata records a commercial-use claim, but the repository does not contain the account receipts, generation records, API authorization, or contract needed to independently verify that claim.

یادداشت‌های تولید پروژه می‌گویند ۳۰ برداشت بی‌کلام زیر برای بازی دیوکش با Suno V6 و از طریق Hoosha API ساخته شده‌اند. **این موسیقی‌ها CC0 نیستند.** در فرادادهٔ پروژه ادعای مجوز استفادهٔ تجاری ثبت شده، اما رسید حساب، سوابق تولید، مجوز API و قرارداد لازم برای تأیید مستقل این ادعا در مخزن موجود نیست.

Before commercial distribution, verify the terms that applied on each generation date and whether the Hoosha API route and its downloads were authorized for the intended use. Keep receipts, terms snapshots, generation/task IDs, and original source files outside this repository. Suno's current help page says commercial-use rights apply to songs downloaded while subscribed to a paid plan, and notes that this does not guarantee copyright protection. Its current Terms also restrict commercial use to permitted downloads obtained through an approved Suno channel. The project should not rely on the commercial-use claim until the third-party API path has been checked.

پیش از انتشار تجاری، شرایط معتبر در تاریخ تولید هر آهنگ و مجازبودن مسیر Hoosha API و دانلودهای آن برای استفادهٔ موردنظر را بررسی کنید. رسیدها، نسخهٔ شرایط، شناسه‌های تولید و فایل‌های اصلی را خارج از این مخزن نگه دارید. طبق راهنمای فعلی Suno، مجوز استفادهٔ تجاری به آهنگ‌هایی مربوط است که هنگام داشتن اشتراک پولی دانلود شده‌اند و این مجوز تضمین‌کنندهٔ حمایت حق‌نشر نیست. شرایط فعلی Suno همچنین استفادهٔ تجاری را به دانلودهای مجاز از مسیر تأییدشدهٔ Suno محدود می‌کند. تا زمان بررسی مسیر API شخص ثالث، نباید به ادعای مجوز تجاری تکیه کرد.

References: [Suno — commercial rights with a paid subscription](https://help.suno.com/en/articles/9601665) · [Suno — Terms of Service](https://suno.com/terms)
